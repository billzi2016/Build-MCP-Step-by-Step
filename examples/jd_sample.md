# Senior AI Systems Engineer

We are hiring an engineer who can build production-grade LLM systems instead of isolated prompt demos.

Key requirements:

- Strong understanding of system prompt design, tool use, and structured model outputs.
- Hands-on experience building multi-step agent runtimes with explicit state management.
- Ability to design or integrate MCP-style capability layers covering tools, resources, and prompt templates.
- Strong Python engineering skills for local tooling, automation, and API integration.
- Ability to turn technical systems into artifacts that are understandable to technical hiring teams and cross-functional partners.

What success looks like:

- Build a local-first agent workflow that can read project material, call tools, and produce structured outputs.
- Make system behavior observable through traces, intermediate state, and failure handling.
- Explain architectural tradeoffs clearly instead of hiding behind generic AI language.
